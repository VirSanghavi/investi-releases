# Investi Desktop releases

Signed and notarized macOS builds and Windows installers for Investi Desktop, published by CI from the private source repo.

- macOS (universal): Developer ID signed, notarized by Apple.
- Windows (x64): not code-signed yet. SmartScreen will warn before it runs. Check the SHA-256 in each release's SHA256SUMS.txt.

Download the latest version from the Releases page.
